## Two checks to run during warm-up week (Sep 3–6) — this decides everything

1. **Discussion group or ad-dump?** Many "Jobs in ..." FB groups only allow
   vacancy posts — no discussion. While commenting Sep 3–6, tag each group:
   - **discussion** (people ask questions, comments flow) → full calendar works
   - **ad-dump** (recruiters post vacancies, nothing else) → NO tip posts;
     comments-only presence there, or leave entirely
   Reallocate any ad-dump group's slots to another discussion group.
2. **Rules per group** — screenshot the pinned rules into TRACKER's "rules
   checked" column; note admin-approval requirements.
