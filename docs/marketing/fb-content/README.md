# Facebook job-group content system

> Created 2026-09-02. Companion to `docs/marketing/launch-plan.md` (§3.7: Swedish
> Facebook groups) and the 10-bucket strategy Anthony approved. This folder is the
> operating manual + the copy. Anthony reviews and posts manually — nothing here
> goes out automatically.

## What this is

A 4-week posting calendar (2026-09-03 → 2026-09-30) of **23 posts**: 22 genuinely
useful / discussion posts and exactly **1** soft product mention (Wed Sep 30).
That is the 80/20 rule made concrete: ~4% product, zero links in post bodies.

Files:

| file | what's in it |
|---|---|
| `CALENDAR.md` | the schedule table — what posts when, which series |
| `GROUPS.md` | the 23-group roster, tiers, language tracks, and which groups get which post |
| `week-0-warmup.md` … `week-4.md` | full post copy, ready to paste |
| `swedish-posts.md` | Swedish versions for the Swedish-language groups |
| `BACKLOG.md` | the rest of the idea library, mapped to series (month 2 runway) |
| `TRACKER.md` | log of what was actually posted where, and results |

## Non-negotiable rules (from the fb-group-post skill + launch plan)

1. **Compliance gate per group, before its first post.** Read the group's rules
   pinned post. If promos/links need admin approval → send the admin DM (below)
   first. The launch plan's verdict: these groups are admin-gated; one yes from
   a large group admin beats every tech platform combined.
2. **New-account warm-up.** The account just joined these groups. Sep 3–6 is
   comment-only: 3–5 genuinely helpful comments per group per day (answer
   someone's question, no links, no "I built something"). First post in a group
   no earlier than Thu Sep 4, and only if the account has commented there first.
3. **Max 1–2 posts per day across ALL groups.** When a post fits two groups,
   post it in one today, the other 2–3 days later with a changed hook (rule 4).
4. **Never post identical text in two groups.** Minimum change: new first line
   + swap one example + adjust the closing question. Facebook's spam detection
   and admins both pattern-match duplicated copy.
5. **No links in post bodies.** Links live in DMs or (only where a group clearly
   tolerates it) in a first comment. Value posts need no links at all.
6. **No hashtags.** They read as marketing in FB groups. One emoji max except
   where a post's structure uses ✅⚠️🎯🚩❓ functionally.
7. **No fabricated credentials.** Anthony's honest angle: a job seeker in Malmö
   who reads a lot of job ads and hiring research and is building a tool. Never
   "as a recruiter" or "in my 10 years of hiring". Frame expertise as
   *"here's what recruiters consistently say"*.
8. **Product claims** (only relevant for the Sep 30 post): say freely — one CV
   on file, jobs found and scored against your experience, tailored CV + cover
   letter drafts, nothing sent without your approval, in beta, Sweden + UK.
   Never — user counts, launch promises, "AI that gets you hired", pricing.
9. **If a post is removed or warned:** stop posting in that group for 30 days,
   re-read the rules, re-approach the admin.
10. **Every comment is future content.** Someone asks a real question in the
    comments → answer it there, then log it in `BACKLOG.md` under "From the
    comments" — that's the content engine.

## Weekly rhythm (once ramped)

| day | series | why |
|---|---|---|
| Mon | ✍️ CV Fix | Monday = "new week, fix the CV" energy |
| Tue | 🔎 Job Ad Breakdown / 🎯 Should I Apply? / 🇸🇪🇬🇧 local | recruiter-speak day |
| Wed | 🎤 Interview Question of the Week | mid-week prep moment |
| Thu | 🧠 Transferable Skills | the signature topic (maps to what the product actually does) |
| Fri | 💬 Interactive / discussion | FB engagement peaks into the weekend |
| ~fortnightly Sun | 🔎 "Drop your job ad" analysis offer | the capability demo, no selling |

Best posting windows for FB job groups (local time): 07:00–08:30, 12:00–13:00,
19:00–21:00. Post once per group per day maximum.

## Comment strategy (this is 80% of the work)

- Answer every question on your own posts within a few hours. Replies are
  engagement; engagement is distribution.
- On other people's posts: be the most useful commenter in the group. No links.
  If someone asks for exactly what JobFinderOS does → answer the question fully
  first, then, only if they seem open: "I'm actually building a tool that does
  part of this — happy to DM you details if useful."
- Log recurring comment questions in `BACKLOG.md` → they become next month's posts.

## Admin-DM template (adapt per group, send before first post if rules are strict)

> Hi! I recently joined [group] — I'm job hunting myself in Malmö and have ended
> up knowing a lot about CVs and job ads along the way. I'd like to start sharing
> free, plain-English job-search tips here (no links, nothing for sale). Wanted
> to check with you first that regular tip posts are okay with the group rules.
> Happy to send you a sample before I post anything. Thanks!

## Images

- `FB Post1.png`, `JobFinder FB image2.png`, `JobfinderFB image.png` (repo root)
  are **product-branded** promo graphics (navy/blue, feature list, beta CTA).
  Use ONLY with the Sep 30 soft product post, and only where rules allow.
  Value posts stay text-only or get neutral tip-card images later — a branded

## Sweden/UK specifics

- Swedish groups largely run in Swedish — GROUPS.md splits the roster into
  SE-Swedish / SE-English / SE-bilingual tracks, and `swedish-posts.md`
  carries the Swedish versions of every post slotted for those groups.
  Anthony is the final language check on every Swedish post.
- Anything touching employment law (kollektivavtal, provperiod, notice periods)
  is marked ⚠️ VERIFY in the copy: re-check current rules at source
  (Arbetsförmedlingen / LAS) before posting. Never post a number or rule you
  haven't verified this month — the launch plan treats stale legal claims as a
  real problem, not a marketing nit.

## Review + tracking

Every post goes to Anthony for edit before publishing. After posting, log it in
`TRACKER.md`: date, group, post, engagement (reactions/comments), any admin
contact, any comment questions harvested for the backlog.
